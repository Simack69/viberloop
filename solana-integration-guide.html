🔗 Solana Wallet Integration Guide

Option 1: Hybrid (Recommended)

  • Firebase for data storage
  • Solana for cryptographic proof
  • Cost: ~$0.0001 per transaction
  • Fast queries & cheap storage
Best for: Production supply chains

Option 2: Full On-Chain

  • All data on Solana blockchain
  • Maximum decentralization
  • Cost: ~$0.001-0.01 per tx
  • Slower data queries
Best for: Maximum transparency

Implementation Steps

1

Add Wallet Connect Button

Replace the role login with wallet connection

<button onclick="connectWallet()">
    Connect Phantom Wallet
</button>
2

Connect to Solana Wallet

async function connectWallet() {
    if (!window.solana) {
        alert('Please install Phantom Wallet');
        window.open('https://phantom.app/', '_blank');
        return;
    }

    try {
        const response = await window.solana.connect();
        const publicKey = response.publicKey.toString();
        console.log('Connected:', publicKey);
        // Save wallet address
        currentWallet = publicKey;
    } catch (err) {
        console.error('Connection failed:', err);
    }
}
3

Create Solana Transaction

async function submitToBlockchain(data) {
    // Create hash of transaction data
    const dataString = JSON.stringify(data);
    const dataHash = await crypto.subtle.digest(
        'SHA-256',
        new TextEncoder().encode(dataString)
    );
    const hashHex = Array.from(new Uint8Array(dataHash))
        .map(b => b.toString(16).padStart(2, '0'))
        .join('');

    // Create Solana transaction with memo
    const connection = new solanaWeb3.Connection(
        solanaWeb3.clusterApiUrl('devnet'), // or 'mainnet-beta'
        'confirmed'
    );

    const transaction = new solanaWeb3.Transaction().add(
        solanaWeb3.SystemProgram.transfer({
            fromPubkey: window.solana.publicKey,
            toPubkey: window.solana.publicKey, // Send to self
            lamports: 1, // Minimal amount
        }),
        // Add memo with data hash
        new solanaWeb3.TransactionInstruction({
            keys: [],
            programId: new solanaWeb3.PublicKey(
                'MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr'
            ),
            data: Buffer.from(hashHex)
        })
    );

    // Sign and send
    const { signature } = await window.solana.signAndSendTransaction(
        transaction
    );

    return signature; // Real blockchain signature!
}
4

Update Firebase with Real Signature

// In your transaction submission
const signature = await submitToBlockchain(transactionData);

const transaction = {
    ...transactionData,
    hash: signature, // Real Solana signature
    walletAddress: currentWallet,
    blockchainNetwork: 'solana-devnet',
    timestamp: firebase.database.ServerValue.TIMESTAMP
};

await database.ref('transactions').push(transaction);
5

Verify on Blockchain

async function verifyTransaction(signature) {
    const connection = new solanaWeb3.Connection(
        solanaWeb3.clusterApiUrl('devnet'),
        'confirmed'
    );

    const txInfo = await connection.getTransaction(signature);

    if (txInfo) {
        console.log('✅ Verified on blockchain');
        console.log('Block time:', txInfo.blockTime);
        console.log('Slot:', txInfo.slot);
        return true;
    }
    return false;
}

Cost Analysis

Approach Cost per Transaction 1000 Transactions Storage
Hybrid (Hash only) ~$0.00001 ~$0.01 Firebase
Memo (256 bytes) ~$0.0001 ~$0.10 Blockchain
Full On-Chain ~$0.001-0.01 ~$1-10 Blockchain

Recommendation: Use Hybrid approach for production. Store full data in Firebase, store cryptographic hash on Solana for immutable proof. Best balance of cost and transparency.
